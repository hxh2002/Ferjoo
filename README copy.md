# 酵种医生 · Dr. Ferjoo

一个纯前端、无需后端的天然酵种互动诊断网页。解压后直接打开 `index.html` 即可使用；所有输入和判断都在浏览器本地完成，不会上传数据。

## 快速开始

1. 解压本项目。
2. 双击 `index.html`。
3. 依次选择当前阶段、喂养比例/种型、高度状态；温度可不填，默认按 25–28℃。
4. 如知道“喂养后已经过几小时”，建议填写。它能避免刚喂完尚未起发时被误判为“活性不足”。
5. 气味、表面颜色、pH、备注均为可选；其中污染迹象拥有最高优先级。

如果某些浏览器的本地安全策略较严格，也可以在项目目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 项目结构

- `index.html` — 页面结构
- `styles.css` — 响应式品牌视觉
- `starter-doctor.browser.js` — 浏览器版规则引擎
- `app.js` — 交互、自然语言填充、经过时间修正、pH 辅助提示
- `assets/` — 用户提供的品牌背景和中英文 Logo
- `source/` — 用户提供的原始知识库与原始 Node.js 规则引擎，保留用于审计
- `KNOWLEDGE-AUDIT.md` — 前置知识审校与科学边界
- `TESTS.md` — 自检覆盖说明

## 核心判断顺序

1. **污染优先**：异色/绒毛状霉变、腐臭/氨味/霉味等覆盖所有活性判断。
2. **阶段覆盖**：起种初期、起种活跃期、起种稳定期、冷藏、复活各自使用独立规则。
3. **成熟种高度判断**：无变化 → 轻微 → 接近翻倍 → 翻倍 → 2–3 倍 → 3 倍以上 → 回落 → 液体层。
4. **比例 × 温度估时**：保留原规则库的基准翻倍时间，再乘温度系数。
5. **经过时间修正**：只有在观察时间达到/超过预期窗口后，才把“几乎不涨”作为较强的活性不足证据。
6. **pH 仅作辅助**：品牌知识库的 3.3–3.8 区间保留为经验目标；4.6 仅作为酸化安全参考线之一，不等同于“单凭 pH 就安全”。

## 重要边界

- 本工具是规则化经验支持，不是微生物检测、医疗或实验室食品安全认证。
- 生面粉/生酵种不应直接食用；最终产品需要充分烘烤。
- 发现有色或绒毛状霉变应弃用整罐，不要仅刮掉表面。
- “液体层/酒精层”本身不等同于霉菌污染，需结合颜色、绒毛与异味判断。
- 预期翻倍时间是经验估算，会受面粉、含水量、接种量、菌群结构、维护历史等影响。
