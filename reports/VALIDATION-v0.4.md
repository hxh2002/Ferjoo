# Ferjoo v0.4 发布验证

## 结论

**PASS**

v0.4 以 v0.2 UI 为基线，选择性合并 v0.3 算法/证据增强，并修复自然语言温度与时间解析回归。

## 自动化门禁

- `npm test`: PASS
- `npm run audit`: PASS
- `npm run enumerate`: PASS
- `npm run review-queue`: PASS
- 核心四轴组合：2,016
- v0.2 → v0.4 核心叙事差异：0 / 2016

核心叙事差异为 0 表示：在完整 `stage × ratio × height × temp` 标准空间中，v0.4 没有无意改变 v0.2 已验证的状态/等级/原因/建议/安全输出；v0.4 的行为变化集中在缺失高度、自然语言解析、证据追踪与高温证据等边界/元数据场景。

## 新增回归覆盖

1. `30℃` 同时保留精确数值 30 与 `t_28_32` 温区；
2. `5h / 5hr / 5hrs / 5hour / 5hours / 5小时` 均可解析；
3. 起种活跃期/稳定期缺失高度时返回明确“信息不足”；
4. `isContaminated()` 可公开调用且否定表达不误报；
5. >32℃ 的非线性分支具备多来源温度/群落证据；
6. 普通诊断附带个体差异不确定性追踪；
7. v0.2 的卡片选择、滑杆、结果面板、双弹窗等 UI 架构仍存在。

## 手工设计约束

- `index.html` 与 `styles.css` 继续沿用 v0.2 的视觉/布局体系；
- 未采用 v0.3 的 select/form 重构 UI；
- 仅更新版本标识与与算法边界相关的交互行为。
