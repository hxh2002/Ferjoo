Ferjoo · UI 与交互设计规范 1.0
日期：2026-10-28 / 状态：设计提案

使用
1. 解压整个文件夹后，用现代浏览器打开 index.html。assets 文件夹需与其保持相对位置。
2. 可离线浏览。可点击章节、复制色值、试用组件、切换原型页面、放大参考图。
3. 页面顶部“打印 / 存为 PDF”调用浏览器打印，打印时展开所有组件说明。建议开启背景图形。
4. 另附 Ferjoo-UI-Design-Guidelines.html 单文件版本，已内嵌需要的字体、图片、样式和脚本。

重点
13 个章节：设计方向、参考取舍、品牌、色彩、字体、布局、图标、组件、交互、页面、状态文案、无障碍、交付。
4 个可切换原型页面；支持记录校验、保存成功、模拟失败与重试、未保存修改提示、日期回看、份数边界、温度单位、模拟通知权限。
所有原型数据仅存于当前页面内存。刷新即重置。没有后端、同步、真实系统提醒或账号功能。

文件
index.html：主文档。
assets/tokens.css 和 tokens.json：共享语义变量。
assets/style.css 和 app.js：文档与交互实现。
assets/brand：从旧 HTML 提取的原始路径 Logo、反白版与本次新绘的概念酵种罐。
assets/icons：本次新绘的统一 24px SVG 功能图标。
assets/fonts：预览字体与许可说明。
assets/references：用户提供的 10 张参考图的缩略版本，只用于本规范设计分析。
QA.txt：实际完成的检查与限制。

来源与范围
旧规范：设计规范(1).zip 内 ferjoo-visual-guide.html、ferjoo-visual-guide.pdf 与字体附件。
参考：软件参考图.zip 内 5 张 PNG 软件截图和 5 张 JPG 视觉参考。
原始 Ferjoo Logo 的矢量路径与渐变保留；反白版仅更改填色，不改变路径。
参考图不是本次新绘的产品资产；保留其来源用途，不直接挪作生产插画或图标。
所有健康、养护、安全判断和业务公式均需在正式产品中独立核验。规范只提出 UI 与交互行为。
无障碍章节为设计目标。实际验证范围见 QA.txt，正式产品仍需真实设备与读屏复核。
