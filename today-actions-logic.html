A3　二级页「高度预约」的三级选项

本机推送开关
  • 未开启 →「开启云端推送」：请求系统通知权限。
  • 已允许 → 订阅 Web Push，提示「达到所选倍数时会推送到本机」。
  • 已拒绝 → 提示到站点设置重新允许。
  • iOS 非主屏幕 → 提示先「添加到主屏幕」（iOS 16.4+）。
  • 浏览器/环境不支持或非 HTTPS → 明确提示，不提供开关。
  • 已开启 →「关闭本机推送」，服务器停止向本机推送。
每个酵种的提醒阈值（可多选）
  • 2× / 2.5× / 3×（相对本轮基线高度）。
  • 可同时选多个；全部取消即关闭该酵种提醒。
  • 同一轮每个阈值只提醒一次；下一次喂养后可再次提醒。
  • 未关联设备的酵种不产生提醒。
  • 提醒依赖本轮有效基线与当前高度，缺一不触发。
成功后的语义变化：新喂养成为「当前轮」，原当前轮自动以结束原因「下一次喂养」关闭；新轮从收到首个有效高度起即可算膨胀率，图内出现「上轮起点 / 上轮终点 / 本轮起点」三条竖线，高度图横轴从喂养前 10 分钟开始。

  • 本轮状态：标签只显示「已结束」，下一行写明「结束原因：<原因>」。
  • 已持续时长冻结到点击时刻；不再随时间增长。

  • 高度图出现「本轮终点」竖线（距起点 > 5 分钟时）。
  • 记录页同一轮显示已结束；轮次详情的结束原因 = 手动结束 + 具体原因。
  • 面板自动收起，结束错误清空。
失败
不改变本轮状态，面板保留可重试
  • 操作卡顶部显示错误（如网络失败、未登录、找不到喂养记录）。
  • 服务未启用 / 未完成迁移 →「发酵窗口服务尚未启用」。
  • 结束时间非法 / 原因非法 → 对应校验提示。
  • 提交期间所有原因按钮禁用（防重复）。
  • 可换一个原因重试，或「继续观察」放弃。
不能结束的情况：① 该轮已经被更晚的喂养记录关闭（结束原因＝下一次喂养）；② 无喂养记录；③ 正在提交。以上均在前端直接 return，不产生请求。
手动结束的边界：结束时刻取点击瞬间，不接受补填历史时刻；结束后仍可「诊断本轮」做诊断，也仍可「记录下一次喂养」开启新轮。诊断与结束互不影响。

C2　第 1 步：观察（安全优先，决定是否跳步）

颜色 / 霉斑
  • 未见异常 → 正常继续。
  • 彩色斑块 / 绒毛霉菌 → 立即跳到第 3 步核对（风险优先）。
  • 不确定 → 允许下一步，但会跳过背景直接核对。
气味
  • 未见异常 → 正常继续。
  • 明显腐败 / 恶臭 → 立即跳到第 3 步核对。
  • 不确定 → 同上，跳过背景。
主要涨幅表现
  • 几乎没涨 / 轻微上涨 / 接近翻倍 / 约 2 倍 / 峰值超过 2 倍 / 超过 3 倍 / 已回落 / 表面有酒精液层 / 不确定。
  • 诊断模式带自动值与倍数区间说明；可修改。
可选：一句话填写 — 输入自然语言 →「识别为待确认字段」→ 逐项「确认此字段」；颜色与气味识别结果不会被采用，仍须主动选择。未识别到字段时保留原文并提示改用逐项填写。
跳步规则：颜色或气味为「可疑」或「不确定」→ 直接到核对（第 3 步），不再要求填写背景；步骤指示相应显示「第 2 / 2 步」，核对页说明已跳过背景，第 1 步按钮显示「直接核对」。两者均正常 → 第 2 步。核对页返回时，若存在跳步答案则回到第 1 步，否则回到第 2 步。

A 保存新喂养 旧轮立即以「下一次喂养」关闭；新轮从新喂养时间开始，进入基线建立期 本轮卡换新起点、已持续归零重算；结束原因行消失；「结束本轮」重新出现 图表横轴从喂养前 10 分钟开始；四条竖线重排；高度预约阈值按新轮重新计时；记录页新增一轮
B 结束本轮 结束时刻写入；窗口冻结，不再随时间增长 状态标签变「已结束」，下一行显示结束原因；结束按钮消失；诊断本轮占整行 记录页/详情页显示同一原因；图表出现本轮终点线；不再产生新的膨胀率
C 保存诊断 不变 若结论为丢弃/需检查，Today 出现「上次风险结果」横幅 生成观察记录；记录页可查看；不影响发酵窗口与图表
切换设备 清空当前选择与证据后重算 优先保留「未选择酵种」的显式空态；否则自动匹配该设备关联酵种 图表数据来源切换；设备选择会被记住（按账号）
切换酵种 按新酵种最新喂养重算 本轮卡、图表基线、操作区条件全部重算 选择会被记住，记录页默认打开同一酵种
60 秒轮询/刷新 若期间出现新喂养，本轮自动变为已结束 状态、已持续时长、图表与罐状态同步更新 罐状态：正常 / 数据偏旧 / 休眠中 / 传感器异常 / 模式异常

7边界与错误态汇总

这些分支决定了「按钮看起来能点，但结果是否符合预期」，也是排障时最常遇到的路径。

场景表现处理与效果
酵种未关联设备罐状态「未关联设备」；图表不显示；提示暂不显示曲线仍可记录喂养、结束本轮；膨胀率与设备证据为空，状态可能长期「数据不足」。
设备休眠 / 传感器故障罐状态「休眠中 / 传感器异常」；图表排除异常样本本轮不会结束；图表注释说明有多少样本未计入膨胀率、有几段超过 40 分钟无采样。
无任何采样罐状态「暂无数据」；图表空态提示「曲线为空不代表本轮已结束」；仍可结束本轮或记录下一次喂养。
喂养时间早于设备关联起点证据不可用，基线只能手工膨胀率缺失；诊断可手填；这是历史数据归属问题，不是本轮结束。
喂养时间晚于设备关联终点证据不可用同上；需重新关联设备或手填起始高度。
已存在更晚喂养本轮直接显示已结束；结束本轮隐藏无需也无法手动结束；诊断本轮可查看历史轮次。
结束请求失败操作卡顶部错误；面板仍在可重试或放弃；本轮继续按时间增长，不会被误标结束。
喂养保存网络中断草稿冻结 + 错误提示重试沿用同一请求编号；不会重复新增，也不会丢失已填内容。
本机存储不可用喂养页红色提示提交会被拦截，避免无法保证刷新后安全重试。
诊断缺少 feeding 参数「预填信息暂不可用，可继续手工填写」仍可完成三步并生成建议，只是没有自动证据。
诊断证据过期（>40 分钟）提示最新高度或温度证据已过期不预填对应字段；用户可重新测量或手工确认。
建议未登录 / 未选酵种保存按钮禁用或提示结果仍可在本机阅读、复制；登录并选酵种后可云端保存。
同一观察重复保存已保存后按钮禁用沿用原请求编号，避免重复记录。
刷新期间切换设备旧请求结果被丢弃（代次校验）只展示最后一次选择对应的数据，不串数据。
最容易被误读的一点：「设备没数据」「数据偏旧」「传感器故障」都不等于本轮结束；只有「下一次喂养」或「手动结束」才会关闭窗口。因此结束按钮的可见性请以「本轮状态」为准，而不是以曲线是否为空为准。
