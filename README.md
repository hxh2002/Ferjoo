# 酵种医生 · Dr. Ferjoo

“让每一次发酵，都有迹可循。”

一个纯前端的天然酵种互动诊断工具：根据你喂养后的阶段、比例、高度、温度与经过时间，给出下一步该怎么做，并在本地浏览器里完成所有判断，无需登录、无需后端、数据不出你的设备。

## 快速开始

直接打开 `index.html` 即可使用。

也可以在本目录起一个静态服务：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 简单说明

- 输入：阶段、喂养比例、膨胀高度、温度、经过时间（或自然语言描述）。
- 输出：安全提示、当前所处阶段、是否在常见时间范围内、下一步操作与参考文献。
- 隐私：所有计算都在浏览器本地完成，不向任何服务器上传你的输入。

> 本工具是可追溯的经验支持，不替代微生物检测、医疗建议或食品安全认证。出现可见有色或绒毛状霉变时应弃用整罐。

## 算法说明

诊断逻辑集中在 `starter-doctor.browser.js`，按「输入归一化 → 分层判定 → 时间窗口 → 证据追踪」的顺序运行，全部在本地完成。

### 1. 输入归一化

把用户选择（或自然语言）转成四类可计算的维度：

- **阶段**：起种初期 / 活跃期 / 稳定期 / 复活期 / 冷藏期 / 成熟期。
- **比例**：`1:1:1`、`1:2:2`、`1:3:3`、`1:5:5`、`1:2:1`、超大比例（深度重置）。
- **高度**：从「无变化」到「已回落」共 8 档膨胀状态。
- **温度**：按 7 个区间归入离散温度桶，每桶带一个经验系数 `coef`（标准 25–28℃ 记为 `1.0`）。

### 2. 预期翻倍时间

只有**成熟期**才做统一的翻倍估时，其余阶段返回「当前阶段不使用统一翻倍估时」。

计算公式为「比例基础时间 × 温度系数」：

```
预期区间 = 比例基础翻倍时长 × 温度系数
```

- 比例基础时长由 `RATIO_BASE_HOURS` 表给出（如 `1:1:1` 为 4–6 小时，`1:5:5` 为 12–24 小时）。
- 温度越低于 25–28℃ 标准值，系数越大（时间越长）；>32℃ 时不进行线性估时，改为提示先降温到 ≤32℃ 再重新观察。

> 该区间是 Dr. Ferjoo 的经验先验（`brand-empirical-prior`），不是通用文献常数。

### 3. 分层判定

在污染检查通过后，依次执行：

1. **污染检查**：出现异色、绒毛状霉变或腐败异味时，直接判为「已污染，弃用整罐」，优先级最高。
2. **阶段覆盖**：非成熟期按各自阶段给出观察性建议。
3. **高度活性判断**：成熟期按膨胀状态判断活性位置（上升期 / 峰值 / 过峰 / 饥饿等）。
4. **时间上下文**：结合经过时间与预期窗口，区分「观察尚早」「仍在窗口内」「已超过上限（偏慢）」。
5. **温度上下文**：>32℃ 时降低乐观度，提示高温下不可线性外推。

### 4. 证据追踪

每条结论都带 `ruleId` 与引用编号，最终汇总为 `citations`；完整的可审阅文献库位于 `research/`，运行时只内置子集以保证离线可用。`scripts/` 负责枚举场景与生成审核队列，`tests/` 覆盖诊断算法、规则引擎与 UI 回归。

## 测试

项目不依赖第三方测试库，Node.js 18 及以上即可运行：

```bash
npm test          # 运行全部诊断算法、规则引擎、场景遍历与 UI 回归测试
npm run audit     # 对全部 2,016 个输入组合做结构自检
```

`tests/diagnosis-algorithms.test.js` 系统覆盖归一化、自然语言解析、污染检测、pH 分层、预期翻倍时间、阶段覆盖、成熟期活性判断、时间与温度上下文、证据追踪与格式化。
