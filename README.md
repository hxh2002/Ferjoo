“让每一次发酵，都有迹可循。”

一个纯前端、无需后端的天然酵种互动诊断网页。所有用户输入和规则判断都在浏览器本地完成；同时提供 Node.js 入口、有限场景枚举器、可执行回归测试和证据追踪字段。

## 快速开始

直接打开 `index.html`，或在项目目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 单一规则源

`starter-doctor.browser.js` 是浏览器与 Node.js 共用的唯一运行时规则实现；`starter-doctor.js` 仅是 Node 兼容导出。诊断结果包含：

- 结构化状态、原因、动作和安全提示；
- `ruleTrace`：本次命中的稳定规则 ID；
- `evidenceRefs` / `citations`：对应权威资料、论文或明确标注的品牌经验先验；
- `expectedReliable` / `expectedReason`：时间估计是否适用及原因；
- `phAssessment`：pH 辅助分层，不作为生食安全许可。

## 判断优先级

1. 污染与明确食品安全信号；
2. 当前阶段的专属基线；
3. 高度/曲线位置；
4. 喂养后经过时间；
5. 温度、比例和 pH 的适用性修正；
6. 带规则与证据出处的可执行建议。

两个硬边界：

- 观察时间未知不等于 0 小时；没有经过时间时，不会凭“几乎不涨”直接断言活性不足。
- `>32℃` 不再按“越热越快”线性外推；该区间停止精确估时，建议降到稳定温和区间后重新记录完整周期。

## 有限组合遍历

核心四轴为 6 个阶段 × 6 个比例 × 8 个高度 × 7 个温区，共 2,016 个组合。枚举器按确定顺序遍历、校验输出契约并把逐字相同的诊断归入叙事等价类：

```bash
npm test
npm run audit
npm run enumerate

# NDJSON
node scripts/enumerate-scenarios.js --format ndjson -o reports/scenarios.ndjson
```

温度整数、经过时间、pH、颜色和气味不能机械地全部相乘后逐条人工审阅。`research/scenario-model.md` 使用边界代表值、污染优先覆盖、三层等价关系和“无效 / 需澄清 / 少见但可能 / 证据缺口”等分类减少重复，同时保留所有原始输入以便审计。

## 项目结构

- `index.html` / `styles.css` / `app.js` — 静态交互页面；
- `starter-doctor.browser.js` — 唯一规则实现和运行时引用子集；
- `starter-doctor.js` — Node.js 兼容入口；
- `scripts/enumerate-scenarios.js` — JSON/NDJSON 批量遍历与等价类报告；
- `tests/` — 规则语义、证据契约和全量结构回归；
- `research/food-safety-evidence.md` — 食品安全与污染证据子库；
- `research/fermentation-evidence.md` — 温度、时间、比例、pH、群落和膨胀证据子库；
- `research/scenario-model.md` — 组合归并、遍历顺序、停止规则与覆盖指标；
- `research/citation-system.md` — `来源 → 证据摘录 → 观点 → 规则 → 场景 → 输出` 追踪规范；
- `KNOWLEDGE-AUDIT.md` — 产品级科学边界摘要。

## 重要边界

- 本工具是可追溯的规则化经验支持，不是微生物检测、医疗建议或食品安全认证。
- 生面粉、生酵种和生面团不应品尝；最终产品需要按配方充分烘烤。
- 可见有色或绒毛状霉变应弃用整罐；不能只刮掉表面。
- 可流动的深色液层与黑色点状/膜状/绒毛状生长必须分开描述，不能只输入“黑色”。
- pH 4.6 是酸化屏障参考，不是“已灭菌”或“可以生吃”的证明。
- 比例固定时间表仍是待用户曲线校准的品牌经验先验；面粉、含水量、接种量、群落、容器和维护历史都会改变结果。
- 当前把“比例”和“硬种水合度”、把“高度”和“液体层”混在单一轴中；研究文档已把它们列为下一版应拆分的输入模型。
