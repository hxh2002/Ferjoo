# 酵种医生 · Dr. Ferjoo

“让每一次发酵，都有迹可循。”

一个纯前端的天然酵种互动诊断工具：根据你喂养后的阶段、比例、高度、温度与经过时间，给出下一步该怎么做，并在本地浏览器里完成所有判断，无需登录、无需后端、数据不出你的设备。

## 快速开始

直接打开 `index.html` 即可使用。

也可以在本目录起一个静态服务：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 简单说明

- 输入：阶段、喂养比例、膨胀高度、温度、经过时间（或自然语言描述）。
- 输出：安全提示、当前所处阶段、是否在常见时间范围内、下一步操作与参考文献。
- 隐私：所有计算都在浏览器本地完成，不向任何服务器上传你的输入。

> 本工具是可追溯的经验支持，不替代微生物检测、医疗建议或食品安全认证。出现可见有色或绒毛状霉变时应弃用整罐。
