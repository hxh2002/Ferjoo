# References boundary

本目录是参考文献和证据库的唯一归属。

- `runtime-catalog.js`：诊断运行时需要的轻量引用元数据。
- `evidence-registry.json`：完整证据卡注册表。
- `food-safety-evidence.md`：食品安全证据。
- `fermentation-evidence.md`：发酵证据。
- `REFERENCE-AUDIT-v0.5.md`：v0.5 证据审计记录。
- `citation-system.md` / `scenario-model.md`：研究方法和历史设计文档。
- `schemas/`：引用数据 schema。
- `index.js`：运行时唯一公共入口。

注意：部分 v0.5 审计文档为了保留历史可追溯性，会提到重构前的 `starter-doctor.*`、
`research/` 等旧路径；它们描述的是当时被审阅的版本，不再代表 v1.0 运行目录。
